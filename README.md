# Crafting is Magic

An MLP-themed total-conversion mod for Minecraft 1.21.1 (Fabric). Play as a
pony or one of Equestria's other peoples, live in pony villages, make friends,
and learn magic.

It's early and in active development. The design is kept private to avoid
spoilers, so this page stays short on purpose.

## Building

Needs Java 21. From `cim-1.21.1/`:

```
./gradlew build
```

The jar ends up in `cim-1.21.1/build/libs/`.

## Playing

Requires Fabric Loader, Fabric API, Veil and GeckoLib. Mine Little Pony is
recommended so ponies look like ponies. Mod Menu and YACL add an in-game
settings screen.
